# Security Policy

## Supported Versions

The following versions of Account Knocker are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Account Knocker team takes the security of our application and user data extremely seriously. If you believe you have discovered a vulnerability, please adhere to the following responsible disclosure guidelines:

1. **Do not create public GitHub issues** for security-sensitive bugs or zero-day disclosures.
2. Email the maintainer directly at **likthankj751@gmail.com** with details of the vulnerability.
3. Include the following information:
   - Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, authentication bypass)
   - Step-by-step instructions or proof of concept to reproduce the issue
   - Affected endpoints or components
   - Any potential mitigation suggestions

### Response Timeline
- **Initial Acknowledgement**: Within 24-48 hours
- **Triage & Status Assessment**: Within 5 business days
- **Fix & Public Patch Release**: Coordinated with the reporting researcher
