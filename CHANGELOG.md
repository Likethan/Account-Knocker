# Changelog

All notable changes to the **Account Knocker** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-15

### Added
- **Core Security Scoring Engine**: Algorithmic 100-point safety index analyzing connected platform vulnerabilities.
- **Knock AI Copilot**: Google Gemini 2.5 Flash conversational assistant with context injection and smart deterministic fallback.
- **Platform Auditing**: Integration and mock sandbox environments for Google, GitHub, Discord, and Spotify.
- **Interactive Dashboard**: Real-time score visualizer, temporal trend charts powered by Recharts, and dynamic cyber status badges.
- **Data Breach Intelligence**: Service and endpoint (`/api/breach`) for credential leak detection and password entropy analysis.
- **Remediation Workflows**: One-click vulnerability mitigation with instant point restoration.
- **Containerization**: Production Dockerfiles for backend (Python 3.11-slim) and frontend (Node 20 / Nginx) with Docker Compose orchestration.
- **CI/CD Pipelines**: Automated GitHub Actions workflows for backend testing (Python 3.11/3.12) and frontend validation (Oxlint & Vite).
- **Comprehensive Test Suite**: Unit tests covering JWT authentication, scoring deductions, connected accounts, and AI fallback rules.
- **Documentation**: Professional next-level README, API references, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, and LICENSE.
